# Project Doctor — Claude

## الغرض

هذه نسخة Claude من مهارة Project Doctor المشتركة مع Codex في «مدار». المرجع
الملزم هو `CLAUDE.md`، ويجب قراءته كاملًا قبل أي تشغيل أو تحليل، ثم مراجعة
`AGENTS.md` لمعرفة حدود التنسيق بين الوكلاء.

## التشغيل

شغّل من جذر المستودع:

```bash
npm run doctor:ai
```

ويمكن طلب إخراج JSON إلى الطرفية فقط:

```bash
npm run doctor:ai -- --json
```

## حدود السلامة

- Project Doctor أداة قراءة وتشخيص فقط، ولا يملك وضع إصلاح تلقائي.
- لا تثبّت أدوات أو إضافات طرف ثالث، ولا تعدّل Firebase أو Firestore أو Storage أو
  المزامنة أو النسخ الاحتياطي.
- لا تطبع الأسرار أو المفاتيح؛ اكتفِ بمسار الملف وتصنيف الخطر.
- افحص تعريف أوامر `test` و`lint` و`build` و`test:rules`، ثم نفذ البوابات المطلوبة
  يدويًا وفق `CLAUDE.md` لأن البناء قد ينتج ملفات مؤقتة.
- لا تُنشئ تقريرًا محفوظًا داخل المستودع.

## تفسير النتائج

اعرض أولًا «حرج»، ثم «تحذير»، ثم «تحسين»، ثم «سليم». أي تعارض مع `CLAUDE.md`
يتقدم على اقتراحات المهارة. لا تعالج نتيجة تخص البيانات أو Firebase أو المزامنة
إلا بعد موافقة صريحة ونطاق محدد، واحفظ تغييرات المستخدم غير المرتبطة بالمهمة.
