# Project Doctor — Codex

## الغرض

هذه مهارة فحص مشتركة لمشروع «مدار». اقرأ `CLAUDE.md` كاملًا ثم `AGENTS.md`
قبل تشغيلها. الأداة تقرأ بنية المشروع، التعليمات، الاعتماديات، إعدادات Firebase،
مسارات المزامنة، قواعد RTL، والوثائق، ثم تطبع تشخيصًا مصنفًا.

## التشغيل

من جذر المستودع:

```bash
npm run doctor:ai
```

وللاستهلاك الآلي دون حفظ ملف تقرير:

```bash
npm run doctor:ai -- --json
```

## حدود السلامة

- الفحص قراءة وتشخيص فقط؛ لا يصلح أو يحدّث أو يحذف أي ملف.
- لا يثبت اعتماديات أو إضافات، ولا يتصل بـ Firebase لتعديل القواعد أو البيانات.
- لا يعرض قيم الأسرار؛ يعرض مسارًا وتصنيفًا فقط عند العثور على نمط مشبوه.
- بوابات `test` و`lint` و`build` و`test:rules` تُراجع من حيث التعريف وتوفر الأدوات؛
  شغّلها صراحةً في بوابة التحقق المطلوبة بعد الفحص.
- لا تحفظ المخرجات داخل Git إلا إذا طلب المالك ذلك صراحةً.

## عند ظهور نتيجة

ابدأ بالنتائج الحرجة، ثم التحذيرات، ثم عناصر «تحتاج مراجعة بشرية». لا تنفذ إصلاحًا
أو تغييرًا في Firebase أو المزامنة أو النسخ الاحتياطي من نتيجة الفحص وحدها؛ اطلب
نطاقًا وموافقة منفصلين، والتزم دائمًا بـ`CLAUDE.md`.
